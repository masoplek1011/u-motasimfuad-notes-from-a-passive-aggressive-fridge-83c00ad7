A tiny deterministic Node program that writes one original line — a smart fridge's passive-aggressive note to its owner, counted from its own door sensor — to `entry.txt`.

## Run it

```sh
node main.ts
```

It writes the note to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
